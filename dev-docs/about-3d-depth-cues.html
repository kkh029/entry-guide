보너스 문서 「3D는 어떻게 보일까?」

작성일 2026-06-15 대상: 신규 보너스 페이지 docs/about-3d.html + index 링크

“3D 개념을 설명하는 새 문서”를 만들고 어떤 주제가 가능한지 검토한 결과를 정리한다. Entry는 순수 2D 도구이므로, 진짜 3D 엔진이 아니라 평평한 화면이 입체로 보이는 단서(소실점·원근·깊이 단서)를 먼저 미술/지각 관점에서 설명하고 → 인터랙티브 데모로 체감 → 마지막에 Entry 블록으로 흉내내기로 잇는 3단 구성의 단독 개념 페이지로 만들었다.

TL;DR
  • 형식: 시리즈 12편과 별개인 단독 보너스 개념 페이지 docs/about-3d.html(about-entry 계열, 데모 1개 포함).
  • 흐름: ① 소실점·원근 → ② 입체 단서 5종(겹침·크기·높이·그림자·공기원근) → ③ 단서 토글 데모 → ④ Entry 블록 매핑 + ‘깊이’ 변수 한 줄 → ★ 아이소메트릭·회전 도형 미리보기.
  • 핵심 원칙: “입체감 = 평면 위 단서들의 합”, 그리고 “전부 평면 위의 눈속임(착시)”을 .tip.real로 못 박음.
  • 데모: 소실점 원근 격자 + 거리 슬라이더 + 단서 5개 체크박스. 전부 끄면 거대·납작하게 떠 보이고, 켤수록 장면에 녹아듦.
  • 색: 신규 액센트 --c3d #4d7a99(블루프린트 슬레이트) + .c-3d. 시리즈 번호(c1~c12)와 구분되는 비-에피소드 토큰.

배경 — 왜 / 무엇을

사용자가 “3D 개념 문서”를 요청했고, 어떤 주제가 가능한지 검토를 먼저 했다. 탐색 결과 Entry는 스프라이트가 x·y·방향·크기만 갖는 순수 2D 플랫폼이며, 기존 1~12편도 모두 2D 물리, docs/·dev-docs/에 3D 언급이 0건이었다. 따라서 문서의 본질은 “평평한 2D가 어떻게 입체로 보이는가, 그 눈속임을 Entry로 흉내내는 법”(fake-3D)으로 잡았다 — 이는 “2D에서 물리를 흉내낸다”는 시리즈 정신과 일치한다.

초기 계획은 게임/Entry에서 출발했으나, 사용자 피드백으로 소실점과 ‘그림에서 입체를 표현하는 법’(미술·지각)을 먼저 깔고 도구(Entry)는 마지막에 내려오는 순서로 전환했다.

채택 안 — 페이지 구성(3단 + 도전)

  1. 인트로 + .goals — 🔬 3D를 보는 눈(소실점·원근·단서) / 🧩 엔트리로 흉내내기(크기·y·맨앞·투명도·‘깊이’ 변수).
  2. 1부 · 소실점과 원근(.c-3d) — 기찻길/복도가 한 점으로 모임 = 소실점, 지평선, 1점/2점 투시. .tip.real로 “레일은 실제로 평행, 모이는 건 착시”.
  3. 2부 · 입체 단서 5종 — 겹침🧱·크기📏·높이📐·그림자/명암🌑·공기원근🌫️ 카드 그리드(.cue-grid) + “단서들의 합” 요약.
  4. 3부 · 단서 토글 데모 — 아래 별도 절.
  5. 4부 · 엔트리로 흉내내기 — 단서→블록 매핑표(.map-table) + ‘깊이’ 변수 하나로 크기·y·투명도를 한꺼번에 계산하는 코드 박스. 겹침은 맨 앞으로 보내기 한 번.
  6. ★ 더 나아가기 — 아이소메트릭(쿼터뷰)·회전 정육면체(투영)를 .tip.bonus ⭐로 미리보기만, 좌표변환/삼각함수 부담 명시. + .tip.real “전부 평면 위 눈속임”.
  7. 🔧 안 될 때 확인 → ✅ 마무리 체크리스트 → 참고자료 → CTA(→index).

단서 토글 데모 (demoCanvas3d)

설계 — “입체감 = 단서들의 합”을 손으로 증명
  • 장면: 소실점(VP=화면 중앙, 지평선 y=150)으로 수렴하는 원근 격자 + 중앙 길을 따라 멀어지는 캐릭터(도형으로 그림, 이미지 의존 0) + 겹침 기준 덤불(깊이 t=0.5 고정).
  • 거리 슬라이더 t(0~1) → 원근 거리 D = 1 + 4t, 바닥 floorY = 150 + 210/D.
  • 단서 체크박스 5개(각각 독립 토글): 크기(scale=1/D)·높이(feetY=floorY vs 고정 nearY)·겹침(t>0.5면 덤불을 캐릭터 뒤→앞 순서로 그려 가림)·그림자(발밑 타원)·흐림(공기원근: 알파↓ + 색을 옅은 파랑으로 lerp).
  • 가르치는 순간: 전부 끄면 캐릭터가 거대·또렷·덤불 위에 납작하게 떠 보임(슬라이더를 움직여도 변화 없음) → 단서를 켤수록 장면에 쏙 들어감. 🟠 바닥의 “있어야 할 자리” 점선 마커가 항상 정확한 깊이 위치를 표시해 어긋남을 드러냄.
  • 가벼운 구현: 애니메이션 루프 없음 — 슬라이더/체크박스 입력마다 render() 1회. 2편 .try-demo 패턴 재사용(액센트만 --c3d).

흐림은 너무 사라지지 않게 알파 하한(1−0.3t)·색 혼합 상한(min(0.5, 0.6t))을 두고, 덤불은 캐릭터 윗부분이 위로 보이도록 낮춰(겹침이 “뒤에 섰다”로 읽히게) 조정했다.

정확성 (authoring-editing-guide A-3 계열)

  • “진짜 3D 아님”: 소실점=착시, Entry는 단서로 입체를 흉내낼 뿐 — .tip.real 2곳에서 명시.
  • 좌표계: “멀수록 화면 위쪽”을 Entry 위쪽 +y 규칙에 맞춰 “y를 키운다”로 표기(A-3 좌표계 항목과 일치).
  • 난이도 분리: 투영 행렬·삼각함수는 본문에서 빼고 ★도전 미리보기로만(회전 도형은 11편 원운동의 cos·sin 연결로 안내).
  • 레퍼런스: Entry 도움말(생김새·움직임 블록)만 인용. 원근·소실점·공기원근은 미술 일반 개념을 학습자 눈높이로 재서술(외부 직접 인용 없음 → 라이선스 이슈 없음). 미술 도식·캐릭터는 캔버스 도형으로 자체 제작.
