작성일 2026-06-03 관련 PR (생성 예정) 대상: docs/entry-game-11-circular.html

11편 2단계(구심력) 섹션의 모드 토글 데모(직선 진동↔원운동을 번갈아 보여주던 demoCanvasLink11)를, 원과 스프링을 한 화면에 동시에 띄우고 도는 공을 위아래 축으로 투영(그림자)하면 그게 곧 스프링 진동임을 가로 점선으로 증명하는 데모로 교체했다.

TL;DR
  • 토글 → 동시 투영: 한 번에 한쪽만 보이던 .mode-pick 토글(force 적분 vx+=K·(cx−bx))을 제거하고, 왼쪽에 도는 공·오른쪽에 매단 스프링을 항상 같이 그린다.
  • 등속 각운동(각도 기반)으로 전환: angle += omega, by = CY + R·sin(angle). 원이 항상 깔끔하고, 추의 y를 공의 by와 정확히 동일하게 두어 가로 점선이 수학적으로 수평이 된다.
  • 그림자 증거: 공→추 가로 점선 + 가운데 세로 기준선 위 그림자 점으로 "두 높이가 항상 같다"를 시각화. 4단계 보너스 팁("도는 공의 그림자는 스프링")을 글이 아닌 실제 데모로 뒷받침.
  • 주변 카피 정합: .tip.real(기존 '힘기반 타원' 설명)을 "원운동 하나에 좌우·위아래 스프링 둘이 숨어 cos·sin은 사촌 / 게임은 각도만 키워 한 코드로 원도 스프링도"로 재작성. 4단계 보너스 팁에 "위 2단계 데모에서 봤죠?" 포인터 추가.
  • 회전속도 슬라이더(demoOmL11, Demo 1 패턴 재사용) 추가로 "각도 += 회전속도" 핵심 개념을 손으로 체험. 토글 전용 dead CSS(.mode-pick 3블록) 제거.

배경 / 이슈

직전 PR #31(demo-height-unify-and-new-demos.html)에서 11편에 '구심력 = 10편 복원력' 연결 데모를 신규 추가했다. 그 데모는 같은 중심 당기는 힘을 두고 옆 속도만 바꿔 직선 진동(=10편) 또는 원운동 중 하나를 토글로 보여주는 힘 관점 데모였다.

사용자 요청
  • 토글로 둘 중 하나만 보지 말고, 원과 스프링을 동시에 보여달라.
  • 도는 공의 운동을 한 축으로 투영(프로젝션)하면 그게 스프링과 같은 운동임을 보여달라.

설계 확인(AskUserQuestion)으로 ① 기존 토글 데모를 교체, ② 세로축(위아래) + 천장에 매단 스프링(sin 투영)으로 합의했다.

2) JS IIFE 전면 재작성

좌표: 왼쪽 원 중심 (220,200)·R=110, 천장 보 y=40, 스프링 x=545·추 반지름 15, 가운데 세로 기준선 x=380. 핵심은 한 프레임 한 값: ballPos().y를 connector·spring·bob에 모두 공유해 정합을 보장한다.

function ballPos(){
  const r = angle * Math.PI / 180;
  return { x: CX + R*Math.cos(r), y: CY + R*Math.sin(r) };
}
function loop(){
  if (!running) return;
  angle += omega;          // 등속 각운동 → 원은 항상 깔끔
  render();                // render 내부에서 p.y 를 추·점선·스프링에 공유
  requestAnimationFrame(loop);
}

드로잉 헬퍼는 기존 파일 스타일을 재사용: drawSky 그라데이션, setLineDash 점선, 3겹 공(#94562f/#c0744a/흰 하이라이트)을 drawCircle3로 묶어 공·추가 공유. 새로 추가: drawBeam(천장 보+빗금), drawSpringV(bobY)(천장→추 세로 지그재그, span 항상 양수라 가드 불필요), drawConnector(y)(공→추 가로 점선 + 기준선 위 그림자 점). 제거: applyMode/modeBtns/VORB/K/drawForceArrow/drawCoil/drawTrail(남으면 ReferenceError).
