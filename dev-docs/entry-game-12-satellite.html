12편 추가 — 인공위성 (구심력의 정체 = 중력)

작성일 2026-06-03 대상: docs/entry-game-12-satellite.html 신규 + 11편 강등 + 공통 배선

원운동(11편) 다음 편으로 인공위성을 추가했다. 11편이 남긴 수수께끼 — “우주엔 고무줄이 없는데 위성을 도는 구심력은 누가 주나?” — 의 답이 지구의 중력(8편)임을 밝히는 편이다. 핵심 통찰은 “인공위성은 안 떨어지는 게 아니라 계속 떨어지는 중”(자유낙하 + 충분한 접선속도 → 지구가 휘어 도망)이고, 시그니처 데모는 뉴턴의 대포(진짜 1/r² 중력 적분으로 속도에 따라 추락·원·타원·탈출). 12편이 새 마지막 편이 되어 11편을 중간 편으로 강등했다.

TL;DR
  • 물리 다리: 11편 구심력(중심으로 당기는 힘)의 정체 = 8편 중력. 고무줄 장력 → 중력으로 바꾸면 그대로 인공위성.
  • 핵심 개념: 위성은 계속 떨어지는 자유낙하 + 옆으로 빠른 접선속도 → 떨어지는 만큼 둥근 지구가 휘어 비켜 = 궤도. 무중력은 “중력 없음”이 아니라 “함께 떨어짐”.
  • 뉴턴의 대포 데모(demoCanvas12): 발사 속도 슬라이더 하나로 추락(🐢)·원궤도(🟢)·타원(🥚)·탈출(🚀)을 모두 시연. 우주(검은 배경+별) 톤.
  • 기본 구현 = 11편 cos·sin 그대로(중심만 지구). ⭐도전 = 진짜 중력 — 중력 = 700 ÷ (거리×거리), 지구까지의 거리 블록으로 1/r² 인력 적분(데모와 동일 식).
  • 색: 미드나잇 블루 --c12 #3b5a8c (그림자 #2a4268) · .c-satellite.
  • 검증: data-block JSON 8/8 parse OK, 스크립트 2개 new Function 통과, 궤도 적분 시뮬로 v=1.4 추락·v=2.2 이심율 0.00 원·v=2.5 타원·v≥2.9 탈출 확인.

개요

11편 「원운동」은 각도 += 회전속도 + cos·sin으로 “깔끔한 원”을 만들고, 그 원을 도는 힘을 구심력 = 10편 복원력(고무줄/스프링의 중심 인력)으로 설명했다. 그러나 11편 헤더·CTA가 이미 “위성”을 모티프로 썼음에도, 현실 위성은 고무줄이 없다는 점은 열린 질문으로 남아 있었다. 12편은 그 질문에 답하며 시리즈를 땅 위 운동 → 우주 궤도로 닫는다.

주제 자체는 새 물리 법칙을 거의 추가하지 않는다 — 중력(8편)과 원운동/구심력(11편), 관성(3편), 포물선(4편)의 종합이다. 그래서 ‘배우는 개념’보다 통찰의 전환(“안 떨어지는 게 아니라 계속 떨어지는 것”)과 한 데모로 네 가지 궤도를 보는 경험에 무게를 둔다.

설계 다리 — 구심력 = 중력

하나의 힘, 또 하나의 이름

11편: 구심력 = 복원력(고무줄). 12편: 그 구심력의 우주판 정체 = 중력. 손이 고무줄로 공을 당기던 자리에 지구가 중력으로 위성을 당긴다. 도는 원리(관성 ⊥ 중심 인력)는 11편과 동일하고, 당기는 주체만 ‘고무줄 → 중력’으로 바뀐다.

개념 ↔ 구현

🔬 핵심 개념위성 = 자유낙하 + 접선속도(계속 떨어짐) · 구심력의 정체 = 중력(8편) · 뉴턴의 대포(속도 → 추락·원·타원·탈출) · 높은 궤도일수록 느림
🧩 기본 변수궤도반지름(=고도) · 궤도속도 · 각도
🧩 기본 블록11편과 동일: 각도 += 궤도속도 → x = 궤도반지름 × cos(각도) · y = 궤도반지름 × sin(각도) (중심 = 지구 = 0,0)
⭐ 도전(진짜 중력)거리 = 지구까지의 거리 · 중력 = 700 ÷ (거리×거리)(1/r²) · x속도 에 ((0−x)/거리)×중력 더하기(y도) → 속도 적분. y속도 초기값으로 원/타원/추락/탈출 분기
🖼️ 데모뉴턴의 대포 — 발사 속도 슬라이더(1.4~3.4), 🚀발사/↺처음으로. 🔴중력(1/r², 가까울수록 길어짐)·🔵속도 화살표, 별 배경. 추락/탈출 시 종료 상태 표기
게임 맥락위성·궤도 방어 게임 · 유도 미사일 · 블랙홀 빨아들이기 · 달-지구 중첩 공전

설계 결정

  1. “계속 떨어지는 중”을 중심 통찰로 위성=안 떨어진다(X) → 위성=떨어지지만 지구가 휜다(O). 무중력 오개념(“우주엔 중력 없음”)을 .tip + .tip.real(ISS 7.9km/s·90분, 함께 떨어져서 둥둥)로 직접 교정. 4편 포물선(세게 던질수록 멀리)을 ‘무한히 세게’로 확장하는 서사로 자연 연결.
  2. 뉴턴의 대포 = 진짜 1/r² 중력 적분 11편 메인 데모는 운동학(각도)이지만, 12편 메인 데모는 “속도 하나로 네 궤도”를 보여야 하므로 실제 중력 시뮬(semi-implicit Euler, SUB=4 서브스텝)로 구현. GM = v_circ²·r0로 잡아 슬라이더 중앙값(2.2)이 정확한 원이 되게 튜닝. 이로써 ⭐도전 블록 코드와 데모가 같은 물리를 공유.
  3. 기본 구현은 11편 코드 재사용 새 편이라고 새 코드를 강요하지 않음 — “11편 코드 그대로, 중심만 지구”가 학습 부담을 줄이고 11→12 연속성을 강화(반지름→궤도반지름, 회전속도→궤도속도 리네이밍만). 진짜 중력 궤도는 ⭐도전으로 분리(D-4 개념↔구현 분리).
  4. ⭐도전에 지구까지의 거리 블록 사용 1/r² 인력의 거리 r을 직접 sqrt(x²+y²)로 깊게 중첩하는 대신, 엔트리 실제 블록 (오브젝트)까지의 거리로 평탄화 → 블록 가독성↑, 실제 엔트리 작성과 일치. 11편 ⭐(선형 복원력) 대비 분모를 거리×거리로 바꾼 게 유일한 핵심 차이(=중력의 1/r²).
  5. 색: 미드나잇 블루(c12) 우주 톤. 파랑 계열 c2(#4a78b8)·c8 인디고(#5a6fce)와 인접 편(11=테라코타·10=세이지)이 아니라 충돌 적음. 데모 캔버스만 검은 우주 배경 + 별로 ‘우주’ 분위기(다른 편의 하늘색 캔버스와 의도적 대비).

정확성 가드

현실 vs 게임 — .tip.real로 명시
  • 무중력: “중력이 없어서”가 아니라 “정거장·우주인이 함께 떨어져서” 둥둥(자유낙하 동승). 명시적 교정.
  • 중력의 1/r²: 데모 🔴 화살표 길이를 GM/r²에 비례시켜 “가까울수록 길어짐”을 눈에 보이게. 본문은 낮은 궤도가 빠르고(ISS 90분) 달이 느린(27일) 이유로 연결.
  • 기본 구현(각도 cos·sin) = 항상 원: 현실 궤도는 타원(케플러). 깔끔한 원이 필요한 기본은 운동학, 진짜 타원/추락/탈출은 ⭐도전(힘 적분)으로 분리해 “현실 타원 vs 게임 원”을 다시 짚음.
  • 탈출속도: 본문은 7.9km/s(궤도)·11.2km/s(탈출)로 현실 수치 제시. 데모는 화면+여백 이탈을 ‘탈출’로 표기(시각적 단순화).
렌더러 제약 (기존 이슈 재확인)

C블록 자식의 note 누락 한계는 동일 — 단, ⭐도전 블록은 최상위 stack 블록 각각에 note를 달아(거리 재기/1/r²/중심으로 당기기) 줄별 의미가 보이게 했다(계속 반복하기 자식이지만 각 줄이 stack이라 표시됨 — 11편 ⭐와 동일 패턴). 깊이 중첩 reporter(((0−좌표)/거리)×중력)의 모바일 가로 초과는 기존 편과 동일한 알려진 한계.
